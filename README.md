# Штурмовать Universe 🌙

Небольшое интерактивное веб-приложение с приглашением на свидание. Работает как обычная веб-страница и может открываться внутри Telegram Mini App.

## Возможности

- Романтический экран приглашения с кнопками «Конечно» и «Нет» (вторая убегает от указателя и нажатий).
- Выбор одного или нескольких вариантов свидания: музей, парк, тир, аквапарк, театр, велосипеды или другой вариант.
- Выбор даты и времени, ввод пожеланий в заметках.
- Отправка выбранных данных на электронную почту через Web3Forms.
- Экран подтверждения, конфетти и анимированное ночное небо с луной, звёздами, облаками и кометами.
- Масштабирование интерфейса под экран и поддержка Telegram Web App.

## Запуск

Откройте `index.html` в браузере. Для тестирования через локальный веб-сервер можно выполнить:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Для публикации подойдут GitHub Pages и другие сервисы статического хостинга. Для запуска как Telegram Mini App нужен публичный HTTPS-адрес, подключённый к боту через настройки Telegram.

## Настройка отправки

В начале блока `<script>` файла `index.html` находятся настройки:

```js
const WEB3FORMS_KEY = "ВАШ_КЛЮЧ";
const YOUR_EMAIL = "your@email.com";
```

1. Получите access key на [Web3Forms](https://web3forms.com/) для нужного адреса почты.
2. Замените `WEB3FORMS_KEY` на свой ключ.
3. При необходимости измените `YOUR_EMAIL` для резервного сценария `mailto:`.
4. Проверьте отправку тестовой формы.

**Важно:** ключ Web3Forms находится в клиентском HTML и виден посетителям. Используйте ключ, предназначенный для публичных форм, настройте доступные антиспам-ограничения и не помещайте в файл пароли или другие секреты. Резервный `mailto:` зависит от почтового приложения посетителя и может не работать в Telegram.

## Как устроено приложение

Все три экрана находятся в `index.html`:

- `#step-ask` — приглашение;
- `#step-details` — выбор места, даты, времени и заметки;
- `#step-done` — подтверждение успешной отправки.

JavaScript переключает экраны, управляет анимациями и отправляет форму запросом `fetch` к API Web3Forms. CSS оформляет стеклянную панель и ограничивает размеры поля заметок. При большом объёме текста заметки прокручиваются внутри поля, не растягивая панель.

## Технологии

HTML5, CSS3, JavaScript без фреймворков, Canvas API, Web Animations API, Telegram Web App SDK, Web3Forms и Google Fonts.

## Примечания

Приложение не хранит ответы в собственной базе данных. Для отправки данных требуется интернет. Дата, время и варианты свидания не обязательны: если они не заполнены, в сообщении используются значения по умолчанию.
